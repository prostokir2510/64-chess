# 64 CHESS

Мобильный веб-проект шахмат для игры с друзьями по шестизначному коду комнаты.

## Технологии
React + Vite, chess.js, Firebase Authentication, Realtime Database и Cloud Functions.

## Текущий этап
Загружен стартовый клиентский каркас и конфигурация Firebase. Для полноценной онлайн-игры необходимо подключить Firebase-проект и развернуть серверные функции. Не публикуйте приватные ключи и service-account JSON в репозитории.

## Запуск
1. Установите Node.js 20 или новее.
2. Скопируйте .env.example в .env и заполните параметры Firebase Web App.
3. В Firebase Console включите Anonymous Authentication и создайте Realtime Database.
4. Выполните npm install.
5. Запустите npm run dev.
